# 🔤 5 букв

**Словесная головоломка: угадай слово из пяти букв за шесть попыток.**

### ▶️ [Играть](https://mysik-portfolio.vercel.app/five-letters/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Слово дня — одно для всех, меняется в полночь
- Свободный режим с бесконечными словами
- Правильная подсветка повторяющихся букв
- Экранная клавиатура и ввод с физической — даже в английской раскладке
- Статистика: серии, процент побед, распределение попыток
- Кнопка «Поделиться» с результатом в виде эмодзи-сетки

## Стек

JavaScript (ES-модули), CSS-анимации, localStorage, Web Share / Clipboard API. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/five-letters.git
cd five-letters
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
